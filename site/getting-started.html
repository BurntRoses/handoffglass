THE FIRST FIVE MINUTES

A small setup. A clearer next step.

Run locally, connect your agent, then try a visual handoff. No account or remote server is involved.

ON THIS PAGE01 · Install02 · Connect03 · Check04 · Go further
Private engineering preview
01 / 04

Choose how to run it.

Source mode requires Node.js 22+. Desktop previews are unsigned and available through GitHub Actions.

TERMINAL
git clone https://github.com/BurntRoses/handoffglass.git
cd handoffglass
npm ci
npm run verify

Complete desktop use requires an interactive Windows or macOS session. Linux GUI support is not yet verified.

02 / 04

Connect your agent.

Choose a host. The config generator uses your machine's real installation path.

GENERATE YOUR CONFIG
node scripts/configure.mjs claude --compact

Paste the printed settings into your agent's MCP configuration and reload its tools. DeepSeek and WorkBuddy also have optional native integrations.

03 / 04

Check the connection.

Verify the local service before testing on your actual screen.

LOCAL CHECKS
npm run readiness -- --json
npm run test:integration
npm run desktop:demo
◎

The demo requires a real desktop. Running Node tests alone cannot prove cursor passthrough, window focus or OS permission behaviour.

04 / 04

Make it your own.

Choose a visual style and preview templates before inviting your agent into the workflow.
