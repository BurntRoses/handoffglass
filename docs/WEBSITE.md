# 网站结构与性能

网站位于 `site/`，使用静态 HTML、CSS 和 ES modules，无框架、字体下载、远程运行资源或构建步骤。预览：`npm run site:preview`。

| 文件 | 职责 |
| --- | --- |
| `index.html` / `app.mjs` | 首页结构、三种演示场景、完成/拒绝状态 |
| `getting-started.html` / `guide.mjs` | 安装说明与简短三语文案 |
| `base.css` | 两页共用的字体、颜色、文档默认值、语言切换容器和系统偏好 |
| `style.css` | 首页组件、响应式布局、动效；按页面区域排列，保持原级联顺序 |
| `guide.css` | 安装说明布局 |
| `shared.mjs` | 语言选择、避免重复 DOM 写入、复制与焦点恢复 |
| `translations.mjs` | 首页三语文案；安装页不加载 |
| `install-prompts.mjs` | 两页共用的安装口令 |

HTML 中的 `modulepreload` 让浏览器在解析入口脚本前就能发现其静态依赖。不要把文案和样式改为运行时获取，也不要为两页引入常驻轮询、全局观察器或逐帧 JavaScript。

语言选择顺序为 URL `lang` → 本地偏好 → 浏览器语言。重复选择当前语言不写 DOM 或存储；实际切换保留演示结果。首页翻译节点与场景控件只查询一次，动态卡片标题和说明只写一次。连续场景输入合并为一个待执行的文字动画恢复回调，CSS 的动画参数保持原值。

复制按钮只注册一个失焦监听器，合并进行中的重复复制。降级路径在 `finally` 中移除临时输入框并恢复焦点；语言切换或用户移开焦点后，过期复制结果不能覆盖当前标签。两条复制路径都失败时保留原按钮，不显示复制成功。

`npm run test:site` 在隔离 Chromium 中验证两页 × 三种宽度 × 三种语言、三种场景、两种结果、减少动态效果、复制成功/失败/延迟、监听器数量、存储不可用和资源加载范围。测试只使用临时浏览器配置，不写系统剪贴板；权限被拒绝的复制测试使用真实 DOM 选择与模拟的剪贴板提交结果。

需要确认重构保持视觉时，在改动前运行 `npm run test:site -- --baseline`，改动后运行 `npm run test:site -- --compare`。两次使用相同 Electron、字体和操作系统；对比全页像素、各元素布局、样式与动画参数，结果在 `.tmp/site-qa/`。动画固定到同一时间再截图，实际动效另在 CSS 参数中比较。无基线时使用普通测试，不凭空创建比较结果。

静态资源字节数和重复操作的 DOM 变更数来自本地浏览器，不等于公网 LCP/INP 或真实设备帧率。上线后的压缩、缓存、CDN 和网络状况应在实际托管站点测量。
