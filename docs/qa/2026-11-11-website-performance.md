# 网站结构与性能优化 · 2026-11-11

基于 `c73d1bb`，范围为 `site/` 两个页面及其预览和验证入口。界面、内容、功能、动效与响应式断点保持原值。

## 检查和修改

安装页原先加载全部首页样式和三语首页文案。现在只加载共用样式、自己的布局、安装口令和交互逻辑。首页 CSS 按区域拆成可读规则，移除三条没有使用方的终端装饰规则；HTML 用 modulepreload 提前发现模块依赖。下方图标明确宽高，避免图片解码前尺寸不确定。

语言解析、存储、复制与复制反馈集中到 `shared.mjs`。查询结果在初始化时保存；相同语言选择不更新页面；动态卡片在语言切换时不先写回默认提示；快速场景切换只保留一个待执行的文字动画恢复回调。复制按钮固定一个失焦监听器，合并进行中的复制，取消过期反馈，并恢复降级复制后的焦点。两条复制路径都失败时不显示“已复制”。

预览根路径现在跳转到正确的首页位置，保留语言参数，避免相对样式与脚本加载失败。预览仍只对回环地址开放，保持资源路径限制。

## 本地测量

macOS arm64 / Electron 44.10.2 的隔离 Chromium，数值来自 Resource Timing 的未压缩 CSS/JS 字节数，不包含 HTML、图标、HTTP 压缩与缓存。前后使用相同环境和浏览器。

| 对象 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 安装页 CSS | 25,244 B | 2,978 B |
| 安装页 JS | 12,989 B | 5,811 B |
| 安装页 CSS + JS | 38,233 B | 8,789 B（减少 77.0%） |
| 首页：重复选择当前语言 120 次的 DOM 变更 | 8,040 | 0 |
| 安装页：同一操作的 DOM 变更 | 1,560 | 0 |

共用复制与恢复逻辑增加了首页依赖；首页原始 CSS/JS 合计从 37,524 B 到 41,482 B。依赖预加载消除了原先脚本解析后才发现文案模块的串行发现过程，两页之间共享缓存。未把资源体积变化或短时间合成操作宣称为公网首屏、INP 或帧率提升。实际托管站点的缓存、压缩和网络延迟未在本轮测量。
