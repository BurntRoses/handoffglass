# 项目审查与连续会话改造 · 2026-10-20

环境：macOS 26.6.2 / arm64，Node 24.19.0，Electron 44。起点为 `cc35f84`，修改位于 `codex/lifecycle-and-agent-guidance`。

## 已确认的问题与修改

| 问题 | 影响 | 本次修改 |
| --- | --- | --- |
| `session_wait` 先等会话结束再读事件 | 目标丢失等变化不能及时返回 | 直接等待事件游标；已有事件立即返回；断开和超时清理监听 |
| 每一步重新建立会话；用户完成后立即释放所有权 | 核验期间其他 Agent 可占用屏幕，无法连续推进 | 同一 ID 保留所有权经过报告、核验和下一步；最终核验才完成 |
| 原生跟随把 handoff 阶段改成 presenting/observe_app | Agent 可能误读下一步 | 保留 waiting_user/wait_for_user；移动合并且不单独唤醒模型 |
| 总开关仅写偏好 | 旧引导和跟随继续显示 | App/MCP/CLI 立即取消并清除跟随；停用先于定位调用检查 |
| 定位尚未返回时停用、步骤重试、HTTP 回执与 SSE 交错 | 晚到结果可能重新显示标注，重试可能停止跟随，核验卡片可能误关 | 会话写入前复查开关；重试保留当前步骤和跟随；桌面按 revision 应用回执 |
| 卸载按表名删除配置，CLI 解析了 Node 可执行路径 | 可能误删同名用户配置，命令不可用 | 固定目标、安装记录、原始恢复数据、写前比较、失败回滚、逐文件清理 |
| WorkBuddy 连接包覆盖写入、递归清理目录 | 用户改动或额外文件可能丢失 | 全量预检、写前比较、失败回滚、逐文件摘要清单；保留修改和额外文件 |
| WorkBuddy 页面只有复制配置 | 用户需自行拼装连接器 | 首次设置和连接页生成 MCP + Skill 文件夹；明确导入、信任、启用和重载步骤；宿主状态保持未验证 |
| 工具有多组重复入口 | 学习和选择开销增加 | 默认 15 个工具；旧七入口仅在兼容模式开启；结构化返回和 compact 输出 |
| Skill、协议文档与实际接口不一致，能力目录示例类型有误 | 重复观察、错误等待、误报成功 | 同步短初始化说明、选择表、恢复表和按需参数参考；用真实工具 Schema 验证示例；呈现时返回下一游标，跳过已知事件 |
| 下拉控件、浮动反馈和卸载入口难找 | 操作不直观 | 宿主卡片、分段选项、真实笔触预览、内联反馈、总开关、具体移除清单 |
| 文档把写入配置写成已信任/已验证 | 用户无法判断连接状态 | 删除超前承诺，区分本地写入、实际调用和未知宿主状态 |

Agent 只能记录自己报告的独立核验结果；Broker 不会凭完成按钮验证原应用。MCP 不自动点击、输入、授予系统权限或修改宿主审批策略。

## 检查范围

单元和 HTTP 检查覆盖：连续所有权、非法推进、幂等、目标事件、移动合并、游标等待/中断、桌面 SSE 凭据隔离、立即停用、配置恢复、用户改动保留、旧版本 Skill 更新和参考文件清理。MCP 集成覆盖默认、extras 和旧入口兼容目录，以及双客户端所有权、场景更新、取消和全局开关。

真实 Electron 检查使用临时 home/CODEX_HOME/runtime，覆盖 Codex 安装→预览移除→移除→重新连接、WorkBuddy 连接器生成与清理、立即停用活跃引导、卡片和笔触按钮、未保存外观预览、语言、只读定位选择、窄窗口、首次设置、完成报告→等待核验→下一步→最终结束。

截图由 `npm run test:release-ui` 写入 `.tmp/release-ui/`，包含连接页、移除预览、外观深浅色、帮助、窄窗口、首次设置、引导和等待核验。截图检查后修正了首次设置标签换行、连接管理顺序和卡片遮挡目标的布局计算。

## 性能样本

`npm run bench:continuity` 在隔离运行目录、已订阅的本机 Node 游标等待上测量 55 次，预热 5 次：本次 Broker 记录 p95 约 0.01 ms，事件到等待客户端接收 p95 约 0.27 ms、最大 0.32 ms。数据只描述合成本机循环，不包含 OS 输入、Electron 实际绘制、宿主调度或模型推理。它不能用来声称 Codex/WorkBuddy 下一条提示会在该时间内出现。

## 仍需完成的工作

- Windows、物理多屏、不同 DPI、全屏应用和安全桌面的实机验收。
- Codex / WorkBuddy 正式宿主内的端到端人机任务，以及工具发现和模型首字节基准。本次本地连接检查返回 `hostVerified:false`。
- WorkBuddy 已导入连接器的信任、启用、绑定和删除状态没有可用本地接口；不能从包文件推断这些状态。当前仅清理本地生成包。
- 当前不提供应用自删除或清空宿主记忆的命令。旧版未记录的配置保留；完整系统卸载需安装包清单和双平台验收。详见 [清理范围](../INTEGRATION_LIFECYCLE.md)。
- 宿主结束 Agent 回合后，MCP 无法自行唤醒模型。连续等待依赖宿主保持工具循环；Broker 重启丢弃内存会话。
- 原始 2.0 设计中的独立可折叠控制条、完整连接分步向导、语义素材注册表和跨进程会话恢复仍未全部实现。本次交付不将其列为完成。
