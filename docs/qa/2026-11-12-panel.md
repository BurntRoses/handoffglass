# 0.19.1 浮窗体验迭代

## 发现与处理

| 问题 | 处理 |
| --- | --- |
| 设置里的展开项同时绘制前后两套箭头 | 移除旧伪元素，共享 Accordion 的状态箭头 |
| 浮窗状态过长，挤占操作区；挂起仍显示可挂起 | 简短状态、带可访问名称的 icon-sm 操作、独立交付说明 |
| 普通等待与实际处理难以区分 | 等待静态显示，只有最近记录的实际处理阶段使用活动反馈；记录完成不等同于核实 |
| 长内容和展开详情超出原生窗口上限 | 卡片正文滚动，顶部操作和失败提示保持可见；新步骤回到顶部并收起详情 |
| 错误被下一次普通状态刷新清空 | 失败反馈保留至重试或新步骤 |
| 隐藏浮窗仍每秒刷新和发送尺寸 | 清空会话时停止计时与活动，尺寸去重；只安排倒计时或实际阶段过期的下一次刷新 |
| 浮动卡片圆角外仍有不透明矩形 | 原生窗口透明，卡片独立绘制表面与边界 |

## 实际验证

- 219 个单元/Bridge 测试，MCP 握手与连接预检。
- 真实 Electron 浮窗：展开反向、焦点归还、减少动态、挂起/接续、长内容滚动、错误保留、新步骤复位、隐藏后无尺寸刷新。
- 共享发布 UI 回归覆盖连接、移除、显示设置、权限、外观、选择及连续任务；展开项仅一套箭头。
- 本机热路径 10 个样本：HTTP p95 2.1ms，DOM p95 16.9ms，页面捕获 p95 39.7ms。指标不包含宿主模型时间，捕获包含 OS 调度。
- 本机 macOS arm64、单物理显示器。未把 CI 构建当成其他平台的实机交互验收。

实现沿用前端处方已有 Button / Accordion 源码与项目令牌，没有新增 UI 依赖。
