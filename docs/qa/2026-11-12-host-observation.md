## 功能证据

- `npm run handoff:check`：233 项通过，语法、版本、链接与场景检查通过。
- MCP：full 19 工具、host 17 工具、extras 22 工具、legacy 26 工具的真实 stdio 检查通过。双宿主所有权、更新版本、挂起返回、游标、核验与清理继续通过。
- `connection:check` 通过；两个 Skill 通过 skill-creator 校验。
- 打包后的 Electron Node 模式 MCP、包内 Codex/WorkBuddy 安装与自有内容清理、隔离的完整卸载 worker 通过；真实安装包在独立桌面及 Electron MCP 两种启动方式下均复用单 Broker，显示与取消通过。
- Codex 原生临时配置检查通过：17 个工具、两个 Skill、light 模式零命令 Hook、首调、重复安装、卸载及无关配置保留。没有调用模型或信任 Hook。
- 原生服务全部拒绝访问的 Broker 用例仍完成宿主区域绘制、更新、清除、连续呈现及独立核验；原生调用次数为零。能力发现也不调用权限探测。
- 全局 DIP 与截图 frame 映射覆盖负坐标、非整数缩放、窄小目标、贴边区域、多屏独立 frame、相邻屏幕、空隙、越界、过期及布局失效。多屏/DPI 变化为合成用例，未作物理多屏或 Windows 实机结论。
- 真实 Electron 中，独立测试窗口的 1200×840 像素图像对应 600×420 DIP。176×420 DIP 侧栏映射到蒙版；四项 SVG 几何误差断言均小于 0.01 DIP。原生调用为零，未打开任务卡片。
- `test:release-ui` 通过：light 连接完成后不要求 Hook 信任；enhanced 明确提示可选审核；原有设置、卸载、试画、挂起和核验回归通过。

## 体积与本地响应

实际 MCP 工具目录 JSON：full 34,029 字节，host 21,174 字节，减少 37.8%；初始化规则 503 字节。此数据是字节数，不是 token。一次含进程启动的初始化与发现采样为 full 329.3ms、host 339.3ms，不能据此宣称启动变快。

独立窗口宿主区域首次绘制：HTTP 响应 6.0ms，测试观察到 SVG 45.7ms。另有 2 次预热、10 次暖调用：

| 阶段 | 中位数 | 第 95 百分位 |
| --- | --- | --- |
| Broker | 3.6ms | 10.2ms |
| HTTP 响应 | 5.9ms | 13.2ms |
| SVG DOM | 21.0ms | 32.1ms |
| capturePage 返回 | 48.4ms | 50.8ms |

采样不包含模型推理、宿主排队、首次应用启动或截图语义理解；DOM 和捕获含测试查询及系统调度。

## 使用边界

- 固定标记不跟随窗口；窗口移动后必须重新观察并更新。只有可选原生目标拥有本地跟随。
- 图像 frame 只映射单个显示器；混合 DPI 全桌面截图不能直接套用一个缩放值。
- 后台或生命周期 Hook 不能唤醒空闲模型；parked 引导仍由用户返回聊天后接续。
- 本轮不宣称完成受保护 Codex 窗口读取、物理多屏、Windows、签名或公证。

实现和使用方式见 [宿主观察与本地绘制](../HOST_OBSERVATION.md)。本地原始日志与截图收束在 `.tmp/final-0.21.0/`。
