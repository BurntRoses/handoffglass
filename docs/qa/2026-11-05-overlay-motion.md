# 桌面标记与动效升级 · 2026-11-05

基于 `ca4afa5` 的 0.18.0 工程预览继续开发。本次更新代码和预览，不创建正式版本标签。

## 变更

- 按聚焦、点位、圈画、文字、反馈分为五类，19 种标记；补充点、涟漪、双线圈选、区域柔光、删除线和叉记。
- 六种出现/停留效果；三种收起方式。正常用户报告后先退场、再隐藏覆盖窗口；目标失效、暂停、停用和断线立即清除。
- 柔边、清晰边缘、深色聚焦遮罩；目标完整挖空，多目标共用一层暗幕。
- 外观页与试验台共用生产渲染器和结构化目录；更新 MCP 参数、能力目录和技能选型说明。
- 修复试验台未提供 `marks.css`、选项升级丢失容器 ID、模板丢失显式视觉参数的问题。

## 验证

macOS arm64，Electron 44.10.2，隔离临时运行目录；不修改用户宿主配置或系统授权。

| 检查 | 结果 |
| --- | --- |
| `npm ci` | 通过；无新增运行依赖 |
| `npm run handoff:check` | 205 项测试、语法、仓库约定与示例场景通过 |
| `npm run test:integration` | 18 个工具；初始化目录、新参数、连续会话和所有权通过 |
| `npm run connection:check` | 隔离 stdio 检查通过，不代表真实宿主已验证 |
| `npm run test:motion` | 19 格实际 SVG，渐显/轻弹/描绘进度、三种退出、即时清除、系统减少动态效果通过 |
| `npm run test:release-ui` | 分组预览、键盘焦点、收起/恢复、中英文、窄窗口、真实覆盖窗口退场和隐藏、过期清理确认不隐藏新步骤、暂停清除通过 |
| 配套技能校验 | `quick_validate.py skills/visual-handoff` 通过 |
| `npm run test:visual` | 未通过：测试窗口无法获得前台焦点，停止于焦点前置条件；不计为跟随/点击穿透验收 |

动作来自专用测试界面的合成点击。`test:release-ui` 在实际生产桌面入口中完成用户报告 → 可见退出 → SVG 清理 → 隐藏窗口，并用旧渲染序号验证新步骤不被误隐藏。动画进度在真实 Electron CSS/SVG 中采样，结构测试另外覆盖重复清空不重置退出计时、快速重现撤销旧清理和失效立即清除。

Windows 桌面、物理外接显示器、真实 Codex/WorkBuddy 任务、签名公证沿用现有待验收状态；本轮构建不能替代这些实机结果。
