# 0.19 单应用与快速响应

本轮处理两份旧应用构建、简单绘制的多轮工具开销、桌面事件延迟、任务挂起和展开收起行为。

## 实现

- `screen_mark` 一次调用，局部确定显示器中心、样式和自动清除；不读取屏幕内容，不创建核验任务。初始化规则直接给出快速入口。
- Broker 连接缓存；明确未送达的连接拒绝可重新发现服务，结果不明的写操作保留幂等限制。SSE 合并同轮状态并立即传输。
- `execution:parked` 保留桌面引导和原生跟随；等待接口立即返回事件与 `yield_to_user`。挂起不伪造任务完成，恢复后仍独立核验。当前状态内可挂起/接续，模型空闲时不会被插件自动唤醒。
- 前端处方的 shadcn Accordion 源码快照、哈希与许可随仓库交付；面板、控制中心、设置页共享原生 DOM 展开组件。快速反向、焦点移回、inert 和减少动态已覆盖。
- 源码与安装版共用应用身份和实例锁；安装版可加入已有 Broker，后续源码 Broker 优先调用登记的最终应用。

## 验证范围

- `npm ci`、`handoff:check`：217 个测试；MCP 标准/扩展目录、连接预检通过。
- Codex 原生隔离配置加载：19 个工具、两个技能、7 个待审核 Hooks；不代替用户信任。
- 真实 Electron：可中断收起/展开、键盘焦点、不可交互隐藏内容、减少动态、桌面挂起/接续、用户报告与独立核验。
- 10 次热路径样本（2 次预热）：本地 HTTP 响应中位数 2.0ms / p95 2.9ms；SVG DOM 24.0 / 28.7ms；页面捕获 58.2 / 85.9ms。捕获包含 OS 调度，不代表光子延迟；不包含 Codex 模型与宿主调度。
- 发布 UI 回归覆盖连接、移除、设置、试用、全局开关及连续会话。

本机为 macOS arm64、单物理显示器。多显示器负坐标有几何回归，Windows 和多个实物显示器不计入本机实测。
