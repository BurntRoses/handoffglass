# 0.19.2 交互与状态修正

## 复现与改动

| 复现问题 | 实现与证据 |
| --- | --- |
| 同时保存总开关、主题、连续会话，前两项被覆盖 | 原版实测停用后恢复为 `enabled:true`；桌面窗口改走 Broker 的字段 patch，文件写入按目录排队；并发及真实 IPC 回归验证独立字段均保留 |
| 完成后暂停、继续，核验返回 `verification_not_due` | 恢复待核验状态与用户报告来源，仍禁止未核验的下一步；事件流不重复记录用户操作 |
| MCP 重连/Broker 重启丢失待核实操作，暂停任务被恢复 | 恢复凭证轮换时保留待核实与暂停；只保存布尔状态与来源代码；真实进程 SIGKILL 后接续核验通过 |
| 已报告操作却自动收起，返回聊天提示不可见 | 保留精简回执，移除过期操作文字和重复详情；用户仍可主动收起 |
| 桌面“恢复会话接续”看似能唤醒模型 | 桌面只提供挂起；明确提示回到原会话说“继续”，Agent 返回后 attach |
| 消费完终态事件后再次等待耗满超时 | 终态立即返回；等待期间挂起立即返回 `yield_to_user` |
| 外观草稿导致总开关刷新被整体跳过 | 已保存状态与草稿分开，刷新总开关/权限而不丢草稿；保存中的新编辑保留未保存提示 |
| 状态变化重发相同 SVG，重复设置原生尺寸 | 主进程按绘制内容去重，状态变化保留原标记/退出动画；真实渲染器检查未收到重复绘制 |
| 关闭控件定位后旧标记仍可能留到下次轮询 | 撤销时立即移除目标跟随标记，进入明确的权限恢复状态 |

## 验证

- `npm ci`、语法/版本/链接检查、225 项单元与 Bridge 测试、场景校验通过。
- MCP 握手（19 个工具）与连接预检通过。原生 Codex 加载器在隔离配置发现 19 个工具、2 个 Skill 和待审核 Hooks；首调/清理通过。
- 已确认的用户报告在返回桌面前落盘。真实 Broker 进程被 SIGKILL 后，新 MCP 客户端使用旋转凭证接续核验；用户暂停保持至明确继续，原拥有者的旧凭证失效。
- 真实 Electron 发布 UI：连接/卸载/重新连接、本地三步骤、主题/语言、权限、设置 patch、草稿保留、总开关刷新、显示器设置、长内容和焦点通过。
- 真实浮窗：完成回执可见、手动收起/反向展开、焦点归还、减少动态、暂停保留核验、挂起停止等待、错误保留、无隐藏刷新、无同图重绘通过。
- 本地热路径：10 个样本、2 个预热；HTTP p95 2.3ms，DOM p95 16.5ms，页面捕获 p95 35.7ms。捕获包含 OS 调度，不含宿主模型时间。单物理显示器、macOS arm64。
- 运行依赖审计（不含开发和可选依赖）为 0 项；完整依赖审计有 6 项 moderate、无 high/critical，均在 electron-builder/minimatch 构建依赖链。未用建议的旧版降级替代当前构建器。
