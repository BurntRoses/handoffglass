## 0.23 · 验收准备

七宿主已接入共用的安装、状态、启停与归属清理服务。DeepSeek / OpenCode 的附着会话通过原生 API 交付决策事件；挂起会话不唤醒模型。连接页处理操作互斥、失败保留、正确宿主状态、启动入口与选项展开。完整卸载先准备独立移除器，当前运行包退出后再按摘要删除。

2026-11-13 的自动化结果：

- `npm run test:preacceptance` 及后续受影响检查通过：295 项测试、完整/host/extras/legacy 四种 MCP 目录、场景校验、连接自检和插件预览门槛。host 目录为 19 个工具。
- `npm run test:codex-plugin` 通过：隔离 Codex 配置中的原生加载、19 工具/两个 Skill、无模型首次只读调用、更新及卸载；更新复用已记录的 CLI，不依赖 PATH。没有验证模型的绘制审批。
- `npm run test:release-ui` 通过：真实 Electron 的连接管理、安装/启停/清理、取消、引导、外观及展开状态；全部使用隔离目录。
- `npm run test:desktop` 通过：Node Broker、独立 App、Electron Node MCP 三条启动路径，双客户端共用、窗口 DIP 边界、焦点和无变化布局的窗口复用。
- `npm run test:plugin-runtime` 通过：插件目录迁移后，使用复制的 Electron 绘制并清除标记，不依赖源码位置。
- 原生入口使用 TypeScript 5.9.3 和真实 SDK 编译通过：OpenCode `2.2.7`，Cordis `4.1.0`，DSH agent/tools/llm `0.2.2-rc.2`。
- 本地事件回环 55 次有效样本：记录 P95 `0.04 ms`，已订阅游标等待收到事件 P95 `0.51 ms`；不包含 OS 输入、Electron 绘制、宿主或模型时间。

上述检查没有调用模型、安装真实宿主或修改系统权限。当前插件公共发布门槛保留 Windows、物理多屏及七宿主的真实任务记录；[验收入口](HOST_EVIDENCE.md#开始实机验收)包含安装、任务、拒绝、恢复和卸载步骤。独立 App 签名不属于本地插件的门槛。
