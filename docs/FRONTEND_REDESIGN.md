# 前端处方核对与整改

日期：2026-11-11。处方来源：本机“前端处方/skill”中的美学标准、禁止项、文案处方、设计系统工作流、基础规范、网格和图标反馈要求。实际组件快照见 [来源记录](../vendor/frontend-prescription/provenance.json)，项目选择见 [DESIGN.md](../DESIGN.md)。

## 原问题与整改

| 核对项 | 原问题 | 本轮处理 | 验证位置 |
| --- | --- | --- | --- |
| 对齐与网格 | 设置、状态和动作各自堆叠；预览固定装饰坐标 | 共用内容起点；标签/控件列；网站目标圈根据真实按钮 DOM 重算 | 工作台、连接、窄窗口、网站三语言截图 |
| 字阶 | 桌面与预览大量 8–12px 文字 | 正文/按钮 14px 起；元数据 13px；SVG 目标说明 14px | 计算样式、200% 字号与原生卡片 |
| 边界归属 | 卡片套卡片、选中描边与阴影叠加 | 用底色和留白分层；清除选择边框；选中勾选 | 连接卡片、标记选择、分段与显示器选择 |
| 圆角 | 7/9/10/12/17/21px 分散硬编码 | 控件、表面、浮层三级圆角 | 共享令牌与运行截图 |
| 表面与主题 | 网站蓝黑光晕与桌面灰绿皮肤分离 | 使用同一语义令牌；网站深色、桌面深浅色 | 主题截图和计算色值 |
| 对比度 | 深色元数据和浅色绿色说明偏淡 | 重配主/次/弱文本与选中底色；按最终色值测试 | 17 组前景/背景组合，浅深主题 |
| 控件状态 | 无默认结果态；隐藏 select 的禁用状态未同步 | Button 变体共用；复制/保存就地反馈；Radio 同步禁用与 Tab 序 | 真实 IPC 流程、禁用与键盘断言 |
| 焦点隔离 | 宽泛 select focus 阴影；父级边界可能重复表达状态 | focus-visible 底色与文字；选择组和样本容器不描焦点 | 实际键盘与鼠标输入、祖先计算样式 |
| 动效 | 全站 hover 浮起和常驻光晕；演示假固定定位 | 状态驱动短过渡；取消无关漂浮；位置随布局更新 | 生产标记入场/退场及减少动态测试 |
| 文案 | 假口语、比喻、重复眉题；演示出现英文装饰标签 | 标题改成具体任务；合并说明；按钮使用动宾结构 | 中文工作台、连接、设置、网站与预览页 |
| 工程 | CSS 在文件末尾反复追加、多个页面重复皮肤 | 重写页面布局；共享令牌和控件；保留原技术栈 | 语法、仓库检查、打包资源和许可 |

| 页面 | 本轮变化 |

| 连接 | 宿主卡片整面选中并勾选；六步状态按列对齐；配置与移除留在次级入口 |
| 外观 | 生产 SVG 预览；五类标记；预览选择勾选；动效、主题和语言共用切换控件 |
| 帮助与多屏 | 权限与状态内联呈现；显示器选择同一语义；卸载独立分区 |
| 首次向导 | 当前阶段整面强调；连接状态清楚；内容滚动，底部继续/返回固定可达 |
| 桌面步骤卡 | 14px 正文与控件；真实阶段、恢复、暂停和结束；收起后保留控制条 |
| 显示器识别 | 使用同一主题、字阶与间距 |
| 官网与使用页 | 清除渐变标题、光晕、装饰卡片与漂浮；保留场景、三语言、复制、锚点与安装流程 |

| Agent 实机试验页 | 统一字号、选择、按钮、状态与本地样式；保留真实 MCP 试验流程 |
| 交互演示 | 提取内联 CSS；使用共享控件；演示标记根据按钮真实边界定位 |

## 验证

- `npm run handoff:check`：语法、仓库、单元测试与场景契约。
- `npm run test:release-ui`：真实 Electron 和隔离运行目录，检查连接、启停、保存、向导、标记、步骤卡、核验、窄窗口、键盘焦点、禁用和 200% 字号。
- `npm run test:site`：真实 Chromium，18 个页面/语言/视口组合、三场景、结果状态、复制、保存语言、减少动态、文字对比与 200% 字号。
- `npm run test:motion`：真实生产渲染器、19 种标记、三种出现和三种收起、即时撤回与减少动态。
- `npm run test:integration`、`npm run connection:check`：MCP/连接不受前端整改影响。

本轮结果（macOS 25.6.0 / Electron 44）：

- `handoff:check`：213 项单元测试通过，语法、仓库与三份场景检查通过。
- `test:release-ui`：通过；浅深主题 17 组前景/背景组合均达 4.5:1；键盘焦点、鼠标选择、禁用与 200% 字号断言通过。单次 UI 操作到 Broker 状态变化为 53.9ms，含测试查询间隔。
- `test:site`：18 组页面/语言/视口通过；三种场景、两种结果、复制恢复与减少动态通过；演示页的拒绝、报告、核验成功和失败分支通过。
- `test:motion`：19 种标记、三种出现与三种收起、立即撤回、系统减少动态通过。
- `test:integration`、`test:extras`、`connection:check`、`doctor`、`build:notices`：通过。安装包检查新增共享 CSS 资源检查。
- `desktop:demo`：桌面窗口与标记已显示；60 秒无人工操作后正常过期。
- Agent 试验页在隔离 Electron 中通过配色、控件操作、IPC 和 200% 字号检查；`test:visual` 的前台焦点前置检查未通过，后续原生跟随流程未执行。
